## How it works

`main.py` (Python 3.13, stdlib only) copies the bundled `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`. The image is 1024×1024, drawn with
original flat illustrations — no photographs, no network, deterministic.

## Run

```sh
python3 main.py
```
